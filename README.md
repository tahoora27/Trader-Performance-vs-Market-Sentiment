# 📊 Market Sentiment vs Trader Behavior Analysis

## 📌 Objective
Analyze how market sentiment (Fear/Greed) affects trader behavior and performance on Hyperliquid.

---

## 📂 Dataset
- Market Sentiment Dataset
- Trades Historical Dataset

---

## ⚙️ Project Workflow
1. Data Cleaning & Preprocessing
2. Feature Engineering (PnL, Win Rate, Trade Size, etc.)
3. Merging datasets
4. Exploratory Data Analysis (EDA)
5. Segmentation Analysis
6. Predictive Modeling (Logistic Regression)

---

## 📊 Key Insights
- Trader performance varies across sentiment conditions
- Overtrading does not guarantee better results
- Disciplined trading leads to more stable outcomes

---

## 🤖 Model
- Logistic Regression
- Accuracy: **93%**

---

## 💡 Strategies
- Reduce leverage during Fear
- Maintain disciplined trading behavior

---

## ⚠️ Note
Leverage was approximated using a proxy due to lack of direct data.
